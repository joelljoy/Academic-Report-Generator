# 📑 Automated Academic Report Generator

A full-stack academic documentation platform designed to automate the generation of professional reports for educational institutions.

The system enables faculty members and administrators to generate structured PDF and Word reports for workshops, seminars, FDPs, STTPs, outreach programs, certifications, sports activities, and cultural events through a simple web interface.

---

## 🚀 Features

### 📄 Automated Report Generation

Generate professional reports in:

* PDF Format
* Microsoft Word Format

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/joelljoy/Academic-Report-Generator.git
```

### Install Dependencies

Root:

```bash
npm install
```

Frontend:

```bash
cd frontend
npm install
```

Backend:

```bash
cd backend
npm install
```

---

## Database Setup

Import:

```text
academic_report_generator_base.sql
```

into MySQL.

Update database credentials inside:

```text
backend/config/db.js
```

---

## Run Backend

```bash
cd backend
npm start
```

---

## Run Frontend

```bash
cd frontend
npm run dev
```
